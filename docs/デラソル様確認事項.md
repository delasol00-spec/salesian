# 制作会社への確認事項

## 1. 本番環境の接続情報について

本番サーバーへのデプロイ作業を進めるにあたり、以下の接続情報をご共有いただけますでしょうか。

- FTP/SFTP接続情報（ホスト名・ポート・ユーザー名・パスワード）
- SSH接続情報（可能であればご共有ください）
- データベース接続情報（ホスト名・DB名・ユーザー名・パスワード）
- サーバー上のWordPressインストールパス

→ 確認中です！分かり次第連絡します。

## 2. トップページ スライドのリンク先について

スライド内の各バナーにリンクが設定されているかと思いますが、現状では対応する詳細ページが存在しない項目があります。

- リンクなし（`href="#"` または `pointer-events: none`）で実装してよいか？
- それとも、別ページ（例：学校説明会一覧ページ等）へ遷移させる想定か？
→ 各イベントページへリンクさせます。リンク先ページは現在作成中です。
- カスタムフィールドで設定したURLへリンクさせる実装でよいか？
→ URLはなんでも構いません。

## 3. トップページ スライド内「要予約」の表示について

スライド内に「要予約」という文言が含まれていますが、この意味・用途を教えてください。

- 学校説明会など予約が必要なイベントを示すラベルか？
→ はい、予約が必要なイベントを示します。予約不要のイベント時は「予約不要」のラベルが表示されて欲しいです。
- WordPressで動的に出し分ける必要があるか（カスタムフィールド対応が必要か）？
- それとも静的な表示として固定でよいか？
→ 各イベントページへは動的生成になると思います。

## 4. SNS用OGPについて

各ページのOGP画像・タイトル・説明文が納品物に含まれていません。

- OGP画像はご用意いただけるか？
- ページごとに異なるタイトル・説明文を設定する必要があるか、共通でよいか？
→ OGP画像は共通でいいです。画像は別途用意します。
　 説明文は不要です。ページタイトルが表示されれば結構です。
