**→ 対応済み（2026-04-06）**: `guardian/htpasswd` に 6ユーザー（sis2611〜sis2616）が定義されており、`inc/auth.php` に反映・有効化済み。

**【追加確認事項・2026-04-06】**

いただいた `htpasswd` ファイルの内容（例: `sis2611:iqoMA.bP7WDvs`）について確認させてください。

- **コロン（:）より右の文字列はハッシュ化されたもの**（暗号化済みパスワード）と見受けられます。
- ハッシュ化されている場合：元の**平文パスワード**でログインします。いただいたファイルの文字列（`iqoMA.bP7WDvs` 等）はパスワードそのものではありません。
- ハッシュ化されていない場合：いただいた文字列がそのままパスワードになります。

**【確認事項】** いただいた `htpasswd` のパスワード欄は「ハッシュ化済み」「平文」どちらでしょうか？また、ハッシュ化済みの場合は元の平文パスワードをお教えいただけますでしょうか？

現在、保護者ページのBasic認証は**一時解除中**です。パスワードが確定次第、再設定いたします。
