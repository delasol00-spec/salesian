## 2. トップページ スライドのリンク先について

スライド内の各バナーにリンクが設定されているかと思いますが、現状では対応する詳細ページが存在しない項目があります。

- リンクなし（`href="#"` または `pointer-events: none`）で実装してよいか？
- それとも、別ページ（例：学校説明会一覧ページ等）へ遷移させる想定か？
→ 各イベントページへリンクさせます。リンク先ページは現在作成中です。

- カスタムフィールドで設定したURLへリンクさせる実装でよいか？
→ URLはなんでも構いません。

【対応済み】briefing・event の各投稿編集画面にリンク先URLカスタムフィールドを追加済み（briefing: `briefing_button_url` / `outside_button_url`、event: `event_link_url`）。未入力の場合は投稿詳細ページへ自動リンク。外部URLの場合は `target="_blank"` で別タブ表示（トップスライド・公開行事一覧ページ共通）。

## 3. トップページ スライド内「要予約」の表示について

スライド内に「要予約」という文言が含まれていますが、この意味・用途を教えてください。

- 学校説明会など予約が必要なイベントを示すラベルか？
→ はい、予約が必要なイベントを示します。予約不要のイベント時は「予約不要」のラベルが表示されて欲しいです。

- WordPressで動的に出し分ける必要があるか（カスタムフィールド対応が必要か）？
- それとも静的な表示として固定でよいか？
→ 各イベントページへは動的生成になると思います。

【対応済み】briefing・event 両投稿タイプの編集画面に「要予約フラグ」チェックボックスを追加。トップページスライドに `info-tag bg-blue` クラスで「要予約」または「予約不要」ラベルを動的表示。event の場合は予約期間（`event_period`）もラベル横に表示。briefing の場合は要予約時のみ予約期間（`briefing_web_cancel_period`）を表示。
